# SOC-08 closure — training partners

Closed on 2026-09-22 across contracts, backend and frontend.

## Shipped boundary

- A training partnership is a mutual, explicitly accepted relationship and is
  not inferred from following.
- A request starts `PENDING` and grants no access. The recipient alone can
  accept it; either member can cancel or end it.
- Each active member owns an independent five-flag grant to the other:
  schedule, progress, activity, routines and encouragement. The last flag is
  persisted now so `SOC-09` can use the same recipient control, but this slice
  sends no encouragement.
- Progress, activity and routine grants widen only their matching
  follower-authorized reads. They do not expose body metrics or unrelated
  private profile fields.
- Shared schedule is bounded to seven dated facts: planned-workout count and
  whether the member trained. It does not reveal routine names, exercises,
  prescriptions or notes.
- Blocking or ending deletes the partnership and both directional grants in
  the same transaction. A block still returns the existing not-found boundary.
- Requests are limited to ten per day and each member may hold at most twenty
  partnerships.
