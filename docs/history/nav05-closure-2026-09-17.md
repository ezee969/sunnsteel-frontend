# NAV-05 closure — 2026-09-17

NAV-05 adds restrained, live indicators to the protected navigation without
creating another source of truth. Notifications is now a first-class sidebar
destination, and Schedule exposes only work that still needs action today.

## Product behavior

- Notifications shows the authoritative unread count from
  `NotificationsResponse.unreadCount`. Values above nine display as `9+` to
  keep the navigation quiet, while the link's accessible name retains the exact
  count.
- Schedule shows the number of still-actionable workouts planned today. It uses
  the same derived list as the dashboard and Notifications Today, including
  moves, skips, completed sessions and rotation rules.
- A live session suppresses the Schedule count because the global Resume banner
  already owns that state. The navigation does not duplicate it.
- Unread Notifications uses the dotted bell glyph as a second, non-numeric cue.
  Both indicators remain ink-coloured data text rather than filled badges, so
  they do not compete with the active honour mark or primary actions.
- Notifications receives the correct active marker and `aria-current` state on
  its route. Indicators stay visible in the expanded drawer and desktop shell,
  and compact beside the icon in the collapsed desktop shell.
