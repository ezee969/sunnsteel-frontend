# SOC-09 closure — lightweight encouragement

Closed on 2026-09-23 across contracts, backend and frontend.

## Shipped boundary

- Only an active training partner can send an encouragement, and only when the
  recipient's directional `encouragement` grant is enabled.
- The sender chooses exactly one contract-owned prompt: Ready to train, Strong
  session, Good work or Keep going. There is no free text, thread, reply or
  conversation model.
- Each sender-recipient pair may commit at most four encouragements in a rolling
  24-hour window. The count and write share one serializable transaction.
- A missing active partnership, disabled grant, block or moderation hide all
  answer 404 so the endpoint does not reveal which privacy rule denied access.
- The existing notification table is both the delivery record and rate-limit
  evidence. The recipient sees the actor and fixed prompt label.
