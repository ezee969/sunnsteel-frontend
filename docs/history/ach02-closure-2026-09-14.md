# ACH-02 closure — 2026-09-14

ACH-02 ships a stable Renaissance rank ladder on the protected Achievements
page. The delivery uses verified attendance data already maintained by the
analytics projection and introduces no migration, backfill or persisted rank
state.

## Product behavior

- The ladder is Initiate, Apprentice, Artisan, Maestro, Virtuoso and Laureate.
- Every promotion requires both a completed-session threshold and a distinct
  active-week threshold. An active week has at least one completed session.
- The criteria reward participation and sustained attendance. Absolute weight,
  volume, body metrics, records and consecutive-day streaks do not affect rank.
- Completed sessions and historical active weeks are monotonic, so an earned
  rank cannot be lost when a current streak ends.
- The page shows the current rank, the attendance totals that support it and
  the exact remaining requirements for the next rank. Progress toward each
  individual achievement remains owned by ACH-04.

## Production verification

The authenticated owner request returned HTTP 200 and resolved Artisan from 48
completed sessions and 13 active weeks. The session requirement for Maestro was
already met and three active weeks remained.

Both themes rendered without page overflow, console errors or failed requests
at 320, 375, 390, 430, 768, 1024, 1280 and 1440 px. Mobile stacked the current
and next rank; desktop rendered the two-column open ledger. The complete
production `ui:regression` run passed 353 of 353 cases, including all fourteen
Achievements layouts plus navigation, responsive shell, overlays, hover and
keyboard focus.

The browser pass was read-only. No session, preference, goal or profile data
was changed.
